# Logo NFS-e Nacional (DANFSe)

`logo-nfse-nacional.png` é o logotipo oficial com fundo **#F3F3F3** (cinza do cabeçalho
OpenAC), sem caixa branca.

O original com fundo preto fica em `assets/nfse/logo-nfse-nacional.png` (não versionar
artefatos de comparação). Para regenerar:

1. Remover o preto → PNG transparente.
2. Compor sobre RGB(243,243,243).
3. Salvar aqui como `logo-nfse-nacional.png`.
