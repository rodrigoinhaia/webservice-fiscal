# Schemas XSD — NFS-e Padrão Nacional

XSDs sincronizados com o pacote NuGet `OpenAC.Net.NFSe.Nacional` (pastas `1.00` e `1.01`).

- **Config:** `Fiscal:NFSe:DiretorioSchemas` → `/app/schemas/nfse` (Docker) ou `Schemas/NFSe` local.
- **Não misturar** com os XSD do DFe.NET em `Schemas/` (NF-e/NFC-e).

Documentação operacional: [`docs/SCHEMAS-NFSE.md`](../../../docs/SCHEMAS-NFSE.md).
